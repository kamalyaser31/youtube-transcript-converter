# مفرغ يوتيوب الاحترافي (YouTube Transcriber Pro)

أداة تخصصية لتحويل مقاطع يوتيوب وقوائم التشغيل إلى وثائق نصية مهذبة بصيغة Markdown، مع معالجة لغوية رصينة وتوافق كامل مع قارئات الشاشة في بيئة ويندوز.

## الميزات المعمارية والتقنية
- **واجهة مكتبية عصرية بـ PySide6 (Qt 6):** معمارية نفاذية كاملة متوافقة مع معايير (WCAG 2.1 AA) وقارئات الشاشة (NVDA)، مع ترتيب تنقل منطقي واختصارات لوحة المفاتيح.
- **معالجة غير متزامنة بـ QThread:** تنفيذ عمليات الجلب في خيوط مستقلة مع بث الإشارات اللحظية للتقدم دون تجميد الواجهة.
- **إقلاع فوري لسطر الأوامر (Lazy Import):** استيراد مرجأ لحزم الواجهة الرسومية؛ مما يمنح سطر الأوامر سرعة فائقة واستهلاكاً ضئيلاً للذاكرة.
- **معالجة لغوية أمينة:** صيانة الحروف الهجائية، وحفظ الكلمات الإعرابية ("اللي"، "طيب"، "يعني")، وتطهير اللازمات الصوتية والوسوم، وتجميع الفقرات دلالياً عند علامات الترقيم التامة.
- **تحصين المسارات وتفادي التصادم:** معالجة آمنة لأسماء الملفات عبر `pathlib.Path` وحماية أسماء ويندوز المحجوزة (`CON`, `PRN`, `NUL`).
- **حزمة اختبارات مستقلة:** اجتياز 10 سيناريوهات اختبارية مؤتمتة في `run_tests.py` تغطي كافة الحالات الحدية.

## المتطلبات التقنية
المكتبات مدونة في `requirements.txt`:
```text
PySide6
yt-dlp
youtube-transcript-api
```

## طريقة الاستخدام

### 1. سطر الأوامر (CLI)
لتفريغ مقطع أو قائمة تشغيل وحفظها في مجلد `md/`:
```bash
python youtube_converter.py -i "https://www.youtube.com/watch?v=..." -o md -l ar en
```

### 2. الواجهة الرسومية (GUI)
تشغيل الواجهة إما مباشرة دون معاملات أو عبر وسيط `--gui`:
```bash
python youtube_converter.py --gui
```

### 3. تشغيل حزمة الاختبارات
```bash
python run_tests.py
```

## هيكلية المشروع
- `youtube_converter.py`: نقطة الدخول الموحدة مع استيراد مرجأ للواجهة.
- `converter_engine.py`: محرك الجلب وإدارة الملفات الآمنة وتدفق القوائم.
- `converter_gui.py`: واجهة PySide6 النفاذة المتوافقة مع قارئات الشاشة.
- `text_processor.py`: المعالج اللغوي الوظيفي الرصين.
- `run_tests.py`: جناح الاختبارات السلوكية المستقلة.
- `md/`: مجلد حفظ وثائق التفريغ النهائية.
