# YouTube Transcriber Pro (نسخة مطورة)

أداة متخصصة لتحويل مقاطع يوتيوب وقوائم التشغيل إلى نصوص مكتوبة بصيغة Markdown، مع تحسين لغوي للنصوص العربية باستخدام مكتبة `PyArabic`.

## الميزات الرئيسية
- **دعم قوائم التشغيل:** إمكانية معالجة قائمة تشغيل كاملة برابط واحد.
- **ذكاء جلب التراجم:** يبحث البرنامج عن التراجم اليدوية (Manual) أولاً، فإن لم يجدها انتقل تلقائياً لجلب التراجم المولدة آلياً (Generated) لضمان عدم ضياع المحتوى.
- **التهذيب اللغوي:** معالجة النصوص العربية وتنسيق الفقرات بشكل رصين.
- **التنظيم التلقائي:** حفظ النتائج في مجلد `md/` مع تسمية الملفات بناءً على عناوين المقاطع الأصلية.

## المتطلبات التقنية
يجب توفر المكتبات التالية (موجودة في `requirements.txt`):
- `yt-dlp` (لجلب معلومات المقاطع)
- `youtube-transcript-api` (لاستخراج النصوص)
- `PyArabic` (للتهذيب اللغوي)
- `wxPython` (للواجهة الرسومية)

## طريقة الاستخدام

### عبر سطر الأوامر (CLI)
لتحميل نصوص قائمة تشغيل أو مقطع باللغة العربية:
```bash
python youtube_converter.py -i "رابط_القائمة_أو_المقطع" -l ar
```

### عبر الواجهة الرسومية (GUI)
تشغيل البرنامج دون معاملات:
```bash
python youtube_converter.py
```

## هيكلية المشروع
- `youtube_converter.py`: المدخل الرئيسي للبرنامج (يدعم CLI و GUI).
- `converter_engine.py`: المحرك الجوهري لعمليات الجلب والمعالجة.
- `text_processor.py`: منطق التهذيب اللغوي وتنسيق النصوص.
- `md/`: المجلد الافتراضي لحفظ النصوص المستخرجة.
