# مفرّغ يوتيوب (YouTube Transcriber Pro)

أداةٌ تأخذ رابطَ مقطعٍ على يوتيوب أو قائمةِ تشغيلٍ كاملة، فتجلب نصَّ ترجمته المصاحبة (Captions)، وتُهذِّبه، وتكتبه وثيقةَ Markdown مقسَّمةً فقراتٍ، لكل مقطعٍ ملفٌّ باسم عنوانه. صُنعت أولاً لدروس العلم والمحاضرات العربية، وتعمل بأي لغةٍ لها ترجمةٌ على يوتيوب. ولها واجهةٌ رسومية تامّة النفاذية لقارئات الشاشة، وسطرُ أوامر، ومهارةُ وكيلٍ (Agent Skill) مرفقة.

## ما تصنعه الأداة

- **اختيار الترجمة:** تُقدَّم الترجمة البشرية ثم الآلية باللغات المطلوبة على ترتيبها؛ فإن عُدمتا تُرجم أقرب مسارٍ متاح إلى اللغة الأولى عبر يوتيوب.
- **تهذيب النص العربي:** تُحذف الوسوم والتطويل وحروف التردد («اااا»، «ممم»)، وتبقى الكلمات الدارجة كما نُطقت، وعلامات الترقيم العربية «» ؛ () والصلاة على النبي ﷺ.
- **تقسيم الفقرات:** تُقطع الفقرة عند تمام الجملة بعد نحو 250 حرفاً، ولا تتجاوز 500 حرف.
- **قوائم التشغيل:** تُفرَّغ مقاطع القائمة واحداً بعد واحد؛ وتعثُّر مقطعٍ يُسجَّل سببه ولا يوقف ما بعده.
- **أسماء ملفات آمنة:** تُنقّى العناوين من المحارف الممنوعة في ويندوز وأسمائه المحجوزة (`CON`، `NUL`…)، ولا يُكتب ملفٌّ فوق آخر، بل يُزاد الاسم رقماً (`_1`، `_2`).
- **المقاطع المقيدة:** يُمرَّر ملف كوكيز (`cookies.txt`) للمقاطع المقيدة بالعمر أو عند حجب الطلبات.

## المتطلبات والتثبيت

يلزم Python 3.9 فما فوق، ثم تُثبَّت المكتبات من [requirements.txt](requirements.txt) في مجلد المشروع:

```bash
pip install -r requirements.txt
```

## التشغيل

### الواجهة الرسومية

تُفتح بتشغيل `youtube_converter.py` بلا وسائط (أو بـ `--gui`). وصفحتها من أعلى إلى أسفل: طابور الروابط، ثم الخيارات (اللغات وملف الكوكيز)، ثم مجلد الحفظ، ثم زرّا البدء والإلغاء، ثم شريط التقدم وسجل الحالة. يجري الترتيب على `Tab` بهذا التسلسل، ولكل عنصرٍ اسمٌ تقرؤه NVDA.

| الاختصار | العمل |
|---|---|
| `Alt+U` | الانتقال إلى حقل الرابط (و`Enter` فيه يضيف الرابط إلى الطابور) |
| `Alt+A` | إضافة الرابط |
| `Alt+R` | حذف المحدَّد من الطابور |
| `Alt+L` | حقل اللغات (رموزٌ تفصل بينها فاصلة، نحو `ar, en`) |
| `Alt+B` | اختيار مجلد الحفظ |
| `Alt+S` | بدء التفريغ |
| `Alt+N` | إلغاء العمل الجاري |

ويُعلَن في آخر العمل عددُ ما نجح وما تعثّر؛ وإغلاق النافذة أثناء العمل يُلغيه بأمان.

### سطر الأوامر

| الوسيط | المعنى | المبدئي |
|---|---|---|
| `-i`, `--input` | رابطٌ أو أكثر لمقاطع أو قوائم تشغيل | مطلوب |
| `-o`, `--output` | مجلد الحفظ | `./md` |
| `-l`, `--langs` | رموز اللغات على ترتيب التفضيل | `ar en` |
| `-c`, `--cookies` | مسار ملف كوكيز بصيغة Netscape | — |
| `--gui` | فتح الواجهة الرسومية | — |

```bash
python youtube_converter.py -i "https://www.youtube.com/playlist?list=..." -o md -l ar en
```

وتُحاط الروابط بعلامتي تنصيص لأن فيها `&` و`?`. ورمز الخروج `0` إذا نجحت المقاطع كلها، و`1` إذا تعثّر مقطعٌ فأكثر (وسببه في سطر `[FAIL]`)، و`2` إذا فُقد ملف الكوكيز أو فسد.

## الملف الناتج

يبدأ كل ملفٍّ بعنوان المقطع ورابطه، ثم النص المهذَّب فقراتٍ:

```markdown
# عنوان المقطع
Source: https://www.youtube.com/watch?v=...

الفقرة الأولى...
```

## مهارة الوكيل (Agent Skill)

في المشروع مهارةٌ مطابقةٌ لمواصفة [agentskills.io](https://agentskills.io) باسم `youtube-transcript-converter`، وتعليماتها في [SKILL.md](.agents/skills/youtube-transcript-converter/SKILL.md). تُثبَّت بنسخ مجلدها إلى مسار المهارات عند الوكيل: `.agents/skills/` أو `.claude/skills/`. والمهارة تشغّل سكربتات المشروع، فيبقى المشروع في موضعه.

وتمرّ المهارة بأربع مراحل، لا يُحمَّل في كلٍّ منها إلا ما تحتاجه:

1. **الاكتشاف (Discovery):** لا يقرأ الوكيل من المهارة إلا اسمها ووصفها.
2. **التفعيل (Activation):** تُفعَّل باستدعائها باسمها، لأن الاستدعاء الذاتي معطَّلٌ فيها (`disable-model-invocation`)، وعندئذٍ يُحمَّل `SKILL.md` كاملاً.
3. **المعايرة (Calibration):** يحدد الوكيل من طلبك الرابطَ واللغاتِ ومجلدَ الحفظ، وهل يلزم ملف كوكيز.
4. **التنفيذ (Execution):** يشغّل سطر الأوامر، ثم يقرأ رمز الخروج، ويتحقق من الملف الناتج.
